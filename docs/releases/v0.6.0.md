# Harbor 0.6.0

Gopeed Native 更名為 Harbor，換上新的港口圖示。既有使用者可直接執行安裝包升級，下載紀錄與設定會保留；程式檔名仍為 `Gopeed.Native.exe`。

## 這版的變更

- 可在確認視窗選「稍後下載」，或指定日期與時間開始。請求由背景核心保存，關閉介面後仍保留；重啟核心會補執行已到期的排程。
- 主清單新增「待下載／排程」篩選。按播放可立即開始，右鍵可調整時間或改回稍後下載。失敗項目保留原因，供手動重試。
- 工具列加入「開啟 Torrent」，支援多選；Ctrl+V 可匯入連結與檔案總管複製的 Torrent 檔案。
- 確認視窗顯示後明確設定置頂，跨程序轉交下載請求時傳遞前景啟用權限。開始傳輸後解除置頂。
- 主清單、下載與設定視窗統一原生布局，關閉訊息列後不再留下空白。
- 新版捷徑、更新檢查、README 和專案連結使用 Harbor 名稱。

## 下載

一般安裝請選 `Harbor-Setup-0.6.0-x64.exe`。免安裝版需完整解壓縮 `Harbor-Portable-0.6.0-x64.zip`，再執行 `Gopeed.Native.exe`。附加的 `Harbor-Source-0.6.0.zip` 包含上游核心原始碼；`SHA256SUMS.txt` 可核對下載。

瀏覽器接管使用 Gopeed 官方擴充套件，請關閉擴充套件的「遠端下載」。安裝時若提示瀏覽器 host 仍在使用，關閉瀏覽器後再試。

此版列為預覽版。已完成核心測試、協定檢查、本機 BT 選檔傳輸與 SHA-256 比對、WinUI publish、打包及本機升級。瀏覽器前景操作與新版原生視覺尚待實機驗收，完整範圍見 [維護紀錄](https://github.com/tavricccc/harbor/blob/v0.6.0/docs/harbor-0.6.0.md)。
