# Harbor 0.6.1

這版補上瀏覽器下載接管的安裝引導。Gopeed 官方擴充套件需在瀏覽器另行安裝，Harbor 會提供對應商店與設定步驟。

- 首次開啟主視窗會顯示可略過的「安裝與設定」提示。工具列的更多選單「瀏覽器接管」可再次開啟引導。
- 引導和設定的「連線」分頁提供 Chrome、Edge、Firefox 官方商店連結，並說明如何啟用本機接管、關閉遠端下載及測試。
- 顯示目前 Harbor 的 host 註冊狀態；註冊成功不會被標成擴充套件已安裝。
- README 新增商店入口、安裝流程與技術 badge，另附[接管指南](https://github.com/tavricccc/harbor/blob/v0.6.1/docs/browser-integration.md)。

安裝版使用 `Harbor-Setup-0.6.1-x64.exe`。Portable 需完整解壓縮，再執行 `Gopeed.Native.exe`。升級保留既有下載與設定；完整來源 ZIP 和 `SHA256SUMS.txt` 一併提供。

此版沿用預覽版狀態。瀏覽器內安裝、實際接管與新版原生視覺尚待互動桌面驗收，沒有以 host 註冊或編譯結果代替這些檢查。
