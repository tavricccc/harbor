# 0.2.0 驗證紀錄

環境：Windows 11 x64（10.0.26100）、PowerShell 7、Go 1.27.0、.NET 10、自包含 WinUI 3。安裝程式採目前使用者權限；安裝後逐一比對前端 DLL、核心 EXE 與 AppIcon 的 SHA-256。

## 行為

- 核心必要測試通過：Token 驗證、建立／暫停／核心重啟／續傳、SHA-256 與移除保留檔案；瀏覽器入口先確認、無有效 Token 不接管。
- C# 檢查通過：協定 payload／UTF-8／base64url、CR／LF／CRLF 標頭、Sec-Ch-Ua 引號，以及完成 Open／暫停 Resume／錯誤 Retry／下載中 Pause 的規則。
- 實際 HTTP 入口在前端關閉時只開確認窗；開始前任務數不變，取消也不建立任務。按開始後，同一視窗轉為進度與完成頁。
- UI Automation 核對完成窗第一個「開啟檔案」、第二個「在資料夾中顯示」都可見且啟用；開啟且勾選關閉選項會關閉進度窗。
- 64 MiB ZIP 與文字測試檔下載完成，SHA-256 均與本機來源一致。測試只使用自己建立的 loopback fixture，不執行下載的安裝檔。
- Explorer 定位實測開啟測試目的地並選取檔案，包含空白與中文的檔名；修正將整個 `/select,path` 引數一起引用造成的解析問題。
- 修正最後視窗關閉與瀏覽器請求的交接：最後視窗關閉時解除單一實例註冊，並保留各下載視窗的強引用；更新安裝後立即關閉主窗再送下載，已開啟單一確認窗，取消不建立任務。

## 建置與記憶體

[Windows CI 修正版建置](https://github.com/tavricccc/harbor/actions/runs/36767708750) 已通過，來源 commit 為 `5fee56b`。本機最後安裝版也對應該程式碼，安裝程式回傳成功，前端／核心／ICO 雜湊比對通過。

2026-10-01 本機閒置快照，保留三個已完成任務，沒有進行中的下載：

| 元件 | 私有工作集 | 總工作集 | 私有提交量 |
| --- | ---: | ---: | ---: |
| 核心（關閉前端） | 7.9 MiB | 29.1 MiB | 56.6 MiB |
| 原生前端（開啟主清單） | 79.7 MiB | 187.5 MiB | 160.0 MiB |

兩個程序的私有工作集合計約 87.6 MiB。總工作集包含可共享的系統與 runtime DLL；私有提交量也不是實際常駐 RAM。這是單機快照，沒有與官方 Flutter 版或 AB 在相同工作量下比較，不代表跨硬體或持續下載的用量保證。
